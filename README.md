# TP2-PROGRAMMATION-WEB-FRONT-END


Voici mon TP2 pour le cours de Programmation Web (Front-End) au College de Maisonneuve **fait le 5 septembre 2025**. Création d’un site web statique complet présentant un tournoi de soccer organisé au Québec. Je me suis basé sur de vrai logo d'équipe de foot au Quebec et intégré des vidéos choisi par moi via Youtube.

Link : https://jayjamesnoivo.github.io/TP2-Programmation-web-front-end/

# 🎯 **Objectif du projet :**


L’objectif était de construire un site Web responsive en HTML, CSS et JavaScript, en appliquant les notions vues en classe, incluant :

- Structure HTML5

- Mise en page responsive avec Flexbox / Grid

- Navigation intuitive entre les pages

- Utilisation d’images, tableaux, formulaires et composants visuels

- Bonne organisation des fichiers (assets, css, js, pages…)

---

# ⚽ **Pages du site :**



- **ACCEUIL :**

Présentation du tournoi, dates, lieu et description générale.

- **CLASSEMENT :**

Classement des équipes (Victoires, Défaites, Nuls et Points).

- **RÉSULTATS :**

Liste et horaire des matchs entre les équipes.

- **FORMULAIRE D'INSCRIPTION :**

Permet aux joueurs de s’inscrire au tournoi via un formulaire.
